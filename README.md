# Hyprland Dotfiles

> Clean & minimal Hyprland setup with Arch Linux.

## Stack

- **OS:** Arch Linux
- **WM:** Hyprland
- **Theme:** Tokyo Night
- **Terminal:** Alacritty
- **Shell:** Fish

## Installation

Clone this repo to `$HOME`:

```bash
git clone https://github.com/gilpra/dots-hypr ~/.dotfiles/dots-hypr

cd ~/.dotfiles/dots-hypr
```

Run automatic setup:

```bash
./setup.sh
```
